# Информационное сопровождение интерактивной экспозиции выставочного центра

Учебная практика, РТУ МИРЭА, группа ИКБО-30-24, Ирхин А. В.
Тема: «Работа выставочного центра с интерактивными экспозициями».

Комплекс позволяет куратору публиковать сведения об экспонатах в одном месте, а интерактивным стендам —
получать обновления без пересборки и установки программ, а также собирать статистику обращений посетителей.

## Структура репозитория

| Каталог | Содержимое |
|---|---|
| `docs/bpmn/` | BPMN-модель текущего (AS-IS) процесса: `process_as_is.bpmn` и изображения |
| `docs/data-model/` | Логическая модель данных в нотации Мартина (IE) |
| `docs/algorithms/` | Блок-схемы алгоритмов по ГОСТ 19.701-90 |
| `algorithms/` | Процедурная реализация алгоритмов на Java (Maven, JUnit 5) |
| `algorithms/data/` | Тестовые данные в формате CSV |

Серверная часть (Java, Spring Boot) и веб-клиент стенда (JavaScript, Three.js) будут добавлены на следующих этапах.

## Алгоритмы

| № | Алгоритм | Код | Сложность |
|---|---|---|---|
| 1 | Синхронизация контента стенда: что загрузить, обновить и удалить | `ContentSync` | O(n + m + k log k) |
| 2 | Регистрация событий взаимодействия с проверкой корректности | `EventRegistration` | O(k) на пакет |
| 3 | Агрегация статистики, рейтинг и невостребованные экспонаты | `StatisticsAggregation` | O(k + q log q + x) |

n — экспонатов в плане стенда, m — в манифесте стенда; k — в алгоритме 1 суммарная длина списков изменений, в алгоритмах 2 и 3 число событий; q — экспонатов с обращениями, x — экспонатов экспозиции.

## Как проверить

Требуется JDK 17 или новее. Проект `algorithms` собирается Maven.

**IntelliJ IDEA**

1. File → Open → выбрать файл `algorithms/pom.xml` → Open as Project.
2. Тесты: правой кнопкой по каталогу `src/test/java` → Run 'All Tests'.
3. Демонстрация: открыть `Main.java` → зелёная стрелка у метода `main` → Run.
   Программа читает CSV из `algorithms/data` и выводит результаты трёх алгоритмов.

**Командная строка**

```
cd algorithms
mvn test
mvn -q compile exec:java -Dexec.mainClass=ru.mirea.exhibition.procedural.Main
```

Необязательные аргументы `Main`: каталог данных, id стенда, текущее время (ISO-8601), например
`data ST-01 2026-10-27T18:00:00`.

Если в консоли вместо русских букв видны «????», добавьте в Run Configuration → VM options:
`-Dstdout.encoding=UTF-8`.
