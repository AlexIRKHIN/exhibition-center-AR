# Решения по рецензии Любина С. С. от 16.11.2026

Проверенная версия `exhibition-core`: `2520bdcf17e46758ca08d4f41a9a9f44de398900`.
Снимок всего репозитория: `cd69a1ee35e354eebfacd0cbee65da4fc383de17`.

| Замечание | Решение и проверка |
|---|---|
| 4.1. Пустой идентификатор события | Принято. `IncomingEvent.parse` отвергает пустой и пробельный id до предметных правил, с причиной `BAD_FORMAT`. Тест проверяет также, что корректная запись после ошибок сохраняется. |
| 4.2. Обрезанные CSV-строки | Принято. `CsvFile.read` получает число столбцов схемы, `CsvRow.requireSize` проверяет точное совпадение. `dateTimeOrNull` использует `text`, поэтому отсутствующее поле больше не считается пустым. Окончание периода без даты допустимо при сохранённом последнем разделителе. Проверены все пять справочников, лишний столбец, черновик и открытый период. |
| 4.3. Ключи и ссылки каталога | Принято. `ExhibitionCatalog` проверяет уникальность id выставок, экспонатов, стендов, размещений и версий; проверяет связи экспонат → выставка, размещение → стенд/экспонат, версия → экспонат (включая черновик). Ошибка указывает сущность и id. Контекст файла и строки сохраняется для структурных ошибок CSV; ошибки связей каталога пока не содержат координат CSV, поскольку проверка общая для любого `ExhibitionRepository`. |
| 4.4. Переполнение статистики | Принято. `count`, `totalSec` и их методы доступа имеют тип `long`; компаратор использует `comparingLong`. На 596 524 обращениях по 3600 с сумма равна 2 147 486 400 с, среднее — 3600 с; при равном числе обращений рейтинг остаётся верным. |
| Гонка при параллельном приёме | Запланировано для серверной реализации с БД. Текущий `EventRegistrationService` и `InMemoryEventStore` предназначены для последовательного вызова. Перед многопоточным использованием нужны атомарная вставка, уникальный ключ в БД, преобразование конфликта в `DUPLICATE` и конкурентный тест. |
| Эквивалентность реализаций | Уточнено назначение `DemoDataTest`: он проверяет ожидаемые значения, не вызывает процедурный код. Добавлен `scripts/compare-demo.ps1`: запускает обе программы с одинаковыми CSV и временем, сравнивает весь вывод после исключения единственной вводной строки объектной программы. |

Все четыре подтверждённые ошибки исправлены. Отклонённых рекомендаций нет.
